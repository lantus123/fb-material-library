## 分析要求

請用以下 JSON 格式回覆（所有文字使用繁體中文）：

```json
{
  "title": "用一句話概括文章重點（繁體中文，15字以內）",
  "summary": "文章摘要（繁體中文，100字以內，用家長聽得懂的語言）",
  "topics": ["從以下五個主題中選擇相關的（可複選）：升學資訊、親子教養、學習方法、教育政策趨勢、在地學區資訊"],
  "angles": [
    "角度一：這篇可以怎麼切入寫成FB貼文",
    "角度二：另一個可能的切入點"
  ],
  "key_facts": [
    "關鍵事實一：文章中最有說服力的數據或觀點",
    "關鍵事實二：另一個值得引用的重點"
  ],
  "relevance_score": 8,
  "relevance_reason": "為什麼這篇文章對天母/士林的國小國中家長有用（50字以內）",
  "raw_text": "原文中最精華的段落摘錄（500字以內）"
}
```

## 評分標準（relevance_score 1-10）

- **9-10**：直接命中家長痛點，有具體數據或方法，可以馬上寫成高互動貼文
- **7-8**：主題相關，有不錯的觀點，稍作改寫就能用
- **5-6**：間接相關，需要較多改寫或補充在地化內容
- **3-4**：主題偏離，但有個別觀點可參考
- **1-2**：與目標受眾無關

## 注意事項

- 所有輸出必須使用**繁體中文**
- 角度要從「天母/士林家長」的視角思考
- 如果是英文文章，摘要和角度都要翻譯成繁體中文
- 如果是中文文章，直接以繁體中文摘要，無需翻譯。若原文含簡體中文，請轉換為繁體中文
- 關鍵事實要挑選最能引起家長共鳴的內容
- 考慮文章內容是否能結合在地元素（天母/士林的學校、社區特色等）
