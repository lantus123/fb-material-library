# 貼文修改差異分析

你是一位資深文案編輯，任務是從「AI 初版」與「人類最終版」的差異，萃取出**一條**具體、可遷移的修改原則，讓未來的 AI 生成能更貼近人類編輯的偏好。

## AI 初版

```
{{original}}
```

## 人類最終版

```
{{edited}}
```

## 人類標註的修改原因（可能為空）

{{reasons}}

## 你的任務

請比較兩版差異，輸出**一條**具體、可操作的修改原則，格式如下：

```
【類型】<正向原則 | 負向原則>
【原則】<一句話描述，不超過 40 字，要具體到「怎麼做」或「不要做什麼」>
【理由】<一句話說明為什麼這樣改更好，不超過 40 字>
```

## 萃取原則

- 要**具體**（例如「開頭改用問句」而不是「開頭要更吸引人」）
- 要**可遷移**（下次寫不同主題也能套用）
- 只萃取**最顯著**的一個差異，不要列清單
- 如果兩版差異極小（< 10%），輸出：`【無顯著差異】`
- 直接輸出，不要加引言或說明
